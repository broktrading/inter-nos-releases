# Inter Nos releases

Installer and update files for Inter Nos, the internal back office of Broktrading.
This repository holds only release files. The source code is private.

Install: download `InterNos-win-Setup.exe` from the latest release and run it.
Windows may show "PC protetto" the first time because the installer is not signed yet: choose "Ulteriori informazioni", then "Esegui comunque".
After that, Inter Nos updates itself.
